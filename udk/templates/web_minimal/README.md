# Minimal Web Application Starter

A clean, semantic HTML5/JavaScript application starter.

## Quick Start
Open `index.html` directly in your browser or run a static server:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## Verification Path
Open the page, enter text in the input box, click "Run Action", and verify the output card updates without JavaScript errors in the console.
